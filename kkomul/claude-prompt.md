## 서비스
부모가 앨범에 아이의 하루를 기록하면, 그 기록으로 아이가 주인공인 동화와 노래를 만들어 주는 구독 서비스.
- **기록 주기:** 한 달에 3~4번
- **기록 내용:** 사진, 그날 있었던 일, 아이가 한 말
- **동화·노래 만들기:** 기록 하나를 골라 ‘동화로’ 또는 ‘노래로’를 누르면 그날 이야기로 작품을 만들어 줌
- **이달의 순간:** 한 달에 한 번, 이번 달 가장 좋아한 말·처음 한 말·처음 한 행동을 적으면 앨범 맨 앞에 모아 줌
- **핵심 어필:** 아이가 힘들어하는 것(양치, 숫자, 단추 등)을 아이가 좋아하는 것으로 풀어낸 동화로 즐겁게 해 줌
- **하지 않는 것:** 영상 제작, 별도 앨범 제작(인쇄 앨범)
- **샘플 주인공:** 이안이(22개월 남자아이, 검은 머리)
- **친구 캐릭터:** 빨간 소방차 「빵빵이」(눈·볼·웃는 입, 노란 경광등)

   - 설명: "한 달에 3~4번, 사진과 그날 있었던 일을 앨범에 남겨 주세요. 양치, 숫자, 단추처럼 아이가 힘들어하는 것도 아이가 좋아하는 것으로 풀어낸 동화와 노래로 만들어 드려요."

   - 떠다니는 칩 2개: "♪ 11월 20일 기록으로 만든 노래", "11월 15일 기록이 올라왔어요"
3. **#uses 활용 예시 (배경 --bg-tint)**

   - 번호가 붙은 접근성 탭 5개(role=tablist, 미리보기 탭과 따로 동작)
   - **1 힘들어하는 것:** "아이가 힘들어하는 것을 좋아하는 것으로 바꿔요". 카드 3장, 각 카드는 그림 → 힘들어해요/좋아해요 태그 → 동화 제목 → 한 줄 → 아이가 얻는 것
     - 양치하기 싫어요 / 소방차 빵빵이 → 「빵빵이와 반짝반짝 양치 출동」
     - 숫자가 싫어요 / 칙칙폭폭 기차 → 「칙칙폭폭, 이안이 기차는 몇 칸?」 (기차 칸을 세며 1~5 익히기)
     - 단추가 무서워요 / 기차, 파인애플 → 「단추가 퐁! 변했어요」 (단추가 기차 연기·파인애플로 변함)
     - 아래 한 줄: "편식, 낯가림, 배변 훈련, 속상한 마음처럼…"
   - **2~5번:** 큰 카드 하나. 왼쪽 그림, 오른쪽에 제목 → 설명 → 「부모가 남긴 기록」(날짜, 글, 아이 말) → ↓ → 「만들어진 작품」 → 아이가 얻는 것
     - 2 행복한 순간: 11/8 에버랜드에서 처음 본 기린 "기린 커! 키 커!" → 노래 「키다리 기린아, 안녕」

## 애니메이션 (GSAP 3.13.0, jsDelivr)
- **불러오기:** gsap, ScrollTrigger, ScrollSmoother
- **구조:** `<header>`는 밖에 두고 `<main>`과 `<footer>`를 `#smooth-wrapper > #smooth-content`로 감쌈. #smooth-content에 padding-top 68px
- **설정:** `ScrollSmoother.create({ smooth: 1.2, smoothTouch: 0.1, effects: true })`
- **히어로:** 첫 등장 타임라인. 스크롤하면 문구·그림·칩이 서로 다른 속도로 움직임(scrub)
- **섹션 제목:** 아래에서 떠오르기 + 약한 패럴랙스
- **활용 예시:** 탭과 카드가 차례로 등장, 카드 그림은 틀 안에서만 살짝 위아래로 움직임(scale 1.1, yPercent ±4)
- **사용 방법:** 단계 카드는 차례로 등장, 작은 화면 그림은 아주 약한 패럴랙스. 2장을 열 때 날짜 카드가 차례로 들어옴
- **앨범 기록:** 책등 4권이 스크롤에 맞춰 아래에서 올라와 꽂힘(scrub)
- **요금제·정보 보호·FAQ:** 카드가 차례로 등장
- **시작 유도:** 박스 scale 0.9→1(scrub), 장식 원은 서로 반대 방향 패럴랙스
- **#링크:** `smoother.scrollTo(target, true, "top 80px")`
- **새로 계산:** 탭 전환, 앨범 보기 전환, 쪽 넘김, FAQ 열기, 폰트 로드 후 `ScrollTrigger.refresh()`
- **칩 애니메이션:** 떠다니는 칩의 CSS 애니메이션은 `transform` 대신 `translate` 속성을 써서 GSAP와 충돌하지 않게
- **끄는 경우:** `prefers-reduced-motion`이거나 GSAP를 불러오지 못하면 애니메이션 없이 기본 스크롤
